隐私与数据说明

小说工厂 · 离线优先创作工具

本地存储：你的作品、章节、创作设置保存在当前设备的浏览器本地存储中。本应用没有账号系统，也不会主动把这些数据上传到任何服务器。清除浏览器数据会导致作品丢失，重要内容请用"导出定稿"另行保存。

模型服务：默认的内置演示引擎在设备本地运行，内容为固定示例。当你在设置中填入 API 地址与密钥接入第三方模型后，创作时章节文本与提示词会发送给该服务商进行处理，并受其隐私条款约束。请在选择服务商前了解其数据政策。

密钥安全：API Key 以明文形式保存在本机浏览器，不会上传，但同一设备上的其他程序或使用者可能读取。请勿在公用设备或不受信任的环境中填写。

内容责任：正文由 AI 生成，可能存在事实错误或不当内容，仅供创作参考。发布前请自行核校事实、版权与合规要求。

权限：本应用仅申请网络访问权限（仅在接入模型、你主动发起创作时使用），不索取通讯录、位置、相册等无关权限。
